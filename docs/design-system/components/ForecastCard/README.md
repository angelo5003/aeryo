One forecast period: date, direction, wind and temperature.

## How to use it

- Pass values already formatted. This card does no unit conversion.

Source: `src/components/surfaces/ForecastCard`. Import from `@/components/surfaces/ForecastCard`.

## Props

| Prop          | Type                                                                           | Required | Default                                                              | What it does                                                                                                                 | Belongs to             |
| ------------- | ------------------------------------------------------------------------------ | -------- | -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `date`        | `string`                                                                       | Yes      |                                                                      | E.g. "Tomorrow, 14:00". Rendered as the card's title, and used to derive the accessible name when `href`/`clickable` is set. | `ForecastCardOwnProps` |
| `direction`   | `string`                                                                       | No       |                                                                      | E.g. "WNW, building through the afternoon". Rendered below the date.                                                         | `ForecastCardOwnProps` |
| `windSpeed`   | `string`                                                                       | No       |                                                                      | Pre-formatted (e.g. "22 kt") — this component does no unit conversion.                                                       | `ForecastCardOwnProps` |
| `temperature` | `string`                                                                       | No       |                                                                      | Pre-formatted (e.g. "24°C").                                                                                                 | `ForecastCardOwnProps` |
| `icon`        | `React.ReactNode`                                                              | No       |                                                                      | Rendered in the media slot (a wind/condition glyph) — this component does not ship its own icon set.                         | `ForecastCardOwnProps` |
| `href`        | `string`                                                                       | No       |                                                                      | Makes the whole card navigate here — see `AeryoCard`'s `href`.                                                               | `ForecastCardOwnProps` |

| `loading`     | `boolean`                                                                      | No       |                                                                      |                                                                                                                              | `ForecastCardOwnProps` |
