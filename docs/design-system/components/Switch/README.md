An on-or-off setting that applies right away.

## How to use it

- Provide the label as `children`. Use `Checkbox` when a form must be submitted first.

Source: `src/components/forms/Switch`. Import from `@/components/forms/Switch`.

## Props

| Prop         | Type                                          | Required | Default | What it does | Belongs to    |
| ------------ | --------------------------------------------- | -------- | ------- | ------------ | ------------- |
| `inputProps` | `React.InputHTMLAttributes<HTMLInputElement>` | No       |         |              | `SwitchProps` |
| `rootRef`    | `React.RefObject<HTMLLabelElement \| null>`   | No       |         |              | `SwitchProps` |
