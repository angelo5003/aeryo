Sora headings in three named sizes.

## How to use it

- Choose `variant`, never a font size. Sora stops at `title`; anything smaller is `Text`.

Source: `src/components/typography/Heading`. Import from `@/components/typography/Heading`.

## Props

| Prop      | Type             | Required | Default     | What it does                                                  | Belongs to     |
| --------- | ---------------- | -------- | ----------- | ------------------------------------------------------------- | -------------- |
| `variant` | `HeadingVariant` | No       | `"heading"` | Semantic heading role — selects the token-backed `textStyle`. | `HeadingProps` |
