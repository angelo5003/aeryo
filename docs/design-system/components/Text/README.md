Manrope body copy in named styles.

## How to use it

- Choose `variant`. Use `body.photo` and `label.photo` on a photo scrim.

Source: `src/components/typography/Text`. Import from `@/components/typography/Text`.

## Props

| Prop      | Type          | Required | Default  | What it does                                               | Belongs to  |
| --------- | ------------- | -------- | -------- | ---------------------------------------------------------- | ----------- |
| `variant` | `TextVariant` | No       | `"body"` | Semantic text role — selects the token-backed `textStyle`. | `TextProps` |
