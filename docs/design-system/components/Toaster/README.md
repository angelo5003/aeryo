Short messages that appear and leave on their own, sent through `toaster.create`.

## How to use it

- Mount `Toaster` once at the app root; the app's provider already does.
- Set `type` to `success`, `warning`, `error` or `info` for the right palette.

Source: `src/components/data-display/Toaster`. Import from `@/components/data-display/Toaster`.

## Props

A pass-through of the matching Chakra UI component: every Chakra prop and style prop works, and resolves to AERYO tokens.
