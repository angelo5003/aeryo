A spot with photo, region, description, wind and rating.

## How to use it

- Pass `windSpeed` and `rating` already formatted.
- `onSave` adds a save button over the photo.

Source: `src/components/surfaces/SpotCard`. Import from `@/components/surfaces/SpotCard`.
