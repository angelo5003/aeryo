A panel that slides in from the left, right or bottom edge.

## How to use it

- Prefer `placement="bottom"` on phones so the content stays within thumb reach.
- Provide `DrawerTrigger` and one `DrawerContent`.

Source: `src/components/data-display/Drawer`. Import from `@/components/data-display/Drawer`.
