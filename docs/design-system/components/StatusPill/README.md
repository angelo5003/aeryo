A small pill for a state, one of the few places a full radius is allowed.

## How to use it

- Keep the word short. Color never carries the meaning alone.

Source: `src/components/data-display/StatusPill`. Import from `@/components/data-display/StatusPill`.

## Props

| Prop      | Type                | Required | Default     | What it does                                                     | Belongs to        |
| --------- | ------------------- | -------- | ----------- | ---------------------------------------------------------------- | ----------------- |
| `variant` | `StatusPillVariant` | No       | `"neutral"` | Visual/semantic variant — selects the token-backed colorPalette. | `StatusPillProps` |
| `size`    | `StatusPillSize`    | No       | `"md"`      | Size.                                                            | `StatusPillProps` |
