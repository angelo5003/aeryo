Lays out children in rows and columns at once.

## How to use it

- Import it from `@/components/primitives`, so app code never imports Chakra directly. Use semantic tokens in its style props.

Source: `src/components/primitives/Grid`. Import from `@/components/primitives/Grid`.

## Props

A pass-through of the matching Chakra UI component: every Chakra prop and style prop works, and resolves to AERYO tokens.
