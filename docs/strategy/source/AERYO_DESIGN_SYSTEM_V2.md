# AERYO Design System

Version: 1.0

---

# Purpose

This document defines the visual and interaction principles of Aeryo.

All future designs should remain consistent with these guidelines.

The goal is not to create a weather application.

The goal is to create a premium discovery platform for wind-driven adventures.

---

# Design Philosophy

Aeryo should feel like:

- Apple
- Patagonia
- Red Bull
- Premium travel products

Combined into a single experience.

The product should feel:

- Premium
- Cinematic
- Intelligent
- Calm
- Technical
- Adventurous

The interface should inspire confidence.

Not excitement.

Not urgency.

Not addiction.

---

# Emotional Goals

When opening Aeryo users should feel:

- Curious
- Prepared
- Inspired
- Confident
- Optimistic

The user should feel:

"There may be an opportunity nearby."

---

# Visual Identity

## Core Attributes

Premium.

Minimal.

Purposeful.

Atmospheric.

Confident.

Never flashy.

Never loud.

Never cluttered.

---

# Color Philosophy

The color system should remain restrained.

Primary influences:

- Deep ocean
- Open water
- Storm systems
- Horizon lines
- Premium marine equipment

Avoid:

- Neon colors
- Bright gradients
- Excessive accent colors
- Tropical surf colors

Color should communicate trust and clarity.

---

# Typography

Typography should be:

- Clean
- Modern
- Highly legible
- Spacious

Hierarchy should be obvious.

Large headlines.

Clear sections.

Comfortable reading rhythm.

Avoid:

- Decorative fonts
- Compressed text
- Dense layouts

---

# Spacing

Whitespace is a feature.

Layouts should breathe.

Avoid cramming information.

Every screen should feel intentional.

Prioritize clarity over density.

---

# Photography

Photography is a strategic asset.

Images should communicate:

- Scale
- Exploration
- Weather
- Atmosphere
- Adventure
- Possibility

Preferred imagery:

- Coastlines
- Open water
- Wind conditions
- Distant horizons
- Riders in natural environments

Avoid:

- Generic stock photos
- Excessive action shots
- Influencer-style content
- Tropical clichés

The best image is often the moment before the action begins.

---

# Cards

Cards should feel:

- Premium
- Spacious
- Easy to scan

Cards should emphasize decisions.

Not raw data.

Example:

Preferred:

Excellent conditions for your 9m kite.

Avoid:

23kt SW.

Translate information into meaning.

---

# Motion

Motion should feel:

- Subtle
- Intentional
- Smooth

Motion should support understanding.

Never use motion for attention seeking.

Avoid:

- Excessive bouncing
- Flashy transitions
- Gamification effects

---

# Icons

Icons should be:

- Simple
- Functional
- Consistent

Icons support content.

Icons do not drive content.

---

# Maps

Maps are secondary.

Opportunities are primary.

Users should first understand:

- Why a location matters

before

- Where it is located

---

# Information Hierarchy

Every screen should prioritize:

1. Opportunity
2. Intelligence
3. Spot Knowledge
4. Community Signal
5. Social Interaction

This hierarchy should never change.

---

# Opportunity First

Every major screen should answer:

Why should I care?

before

What are the details?

---

# Community Design Rules

Community is signal.

Community is not entertainment.

Community elements should support decisions.

Examples:

✓ Active riders

✓ Local observations

✓ Session reports

✓ Conditions updates

Avoid:

✗ Endless feeds

✗ Engagement farming

✗ Social media mechanics

✗ Attention traps

---

# Premium Quality Test

Before shipping a design ask:

Does this feel premium?

Does this feel intentional?

Does this reduce complexity?

Does this support discovery?

If not, redesign it.

---

# Design North Star

The user should always feel:

"There is an opportunity waiting for me."

That feeling is more important than any individual component.
