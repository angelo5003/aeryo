# MVP Goal

Nothing more.

- Save spots
- View forecasts
- Receive recommendations
- Understand session quality

# Scope Protection Rule

Whenever a new feature is proposed ask:

Does this directly help users find a better session?

If no:

Move it to the backlog.

Do not add it to MVP.
