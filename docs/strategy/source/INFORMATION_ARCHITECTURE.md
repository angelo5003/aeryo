# AERYO Information Architecture

Version: 1.0

---

# Purpose

Defines navigation, screen hierarchy and product structure.

---

# Navigation Principles

Navigation should remain simple.

Avoid excessive tabs.

Avoid deep nesting.

The user should find critical information within two taps.

---
