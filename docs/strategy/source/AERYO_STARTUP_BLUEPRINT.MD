# AERYO Startup Blueprint

Version: 1.0

---

# Mission

Help kitesurfers discover better sessions, better locations and better opportunities.

Aeryo exists to reduce uncertainty and help riders make better decisions about where and when to ride.

---

# Vision

Aeryo becomes the operating system for wind-driven adventures.

Today users check weather.

Tomorrow users ask:

"Where should I go?"

Aeryo provides the answer.

---

# Brand Promise

Follow the Unseen.

Aeryo helps riders discover:

- unseen opportunities
- unseen wind windows
- unseen locations
- unseen adventures
- unseen progression

---

# Product Category

Aeryo is NOT:

- a weather app
- a social network
- a tracking app
- a spot directory

Aeryo IS:

- Discovery Intelligence Platform
- Decision Support Platform
- Adventure Discovery Platform

---

# Core User Problem

Current rider workflow:

1. Open Windy
2. Open Windfinder
3. Check spot website
4. Ask friends
5. Check WhatsApp
6. Check Instagram
7. Guess

Result:

Too much information.

Not enough confidence.

---

# Aeryo Solution

Aeryo transforms raw weather information into actionable decisions.

Input:

- Forecast models
- Wind
- Gusts
- Tide
- Spot data
- User preferences
- Session history
- Community reports

Output:

- GO
- MAYBE
- NO-GO

With clear explanations.

---

# Core Product Principle

The app should answer:

"Where should I ride?"

before answering:

"Who is riding?"

Community is important.

Community is supporting information.

Opportunity is primary.

---

# Product Philosophy

Aeryo is Intelligence First.

Community Second.

Every feature should increase confidence in a riding decision.

Every feature should help users discover opportunities.

---

# North Star

Help riders find their next great session.

---

# Target User

## Primary User

The Progression Rider

Characteristics:

- 25-45 years old
- Limited free time
- Actively improving
- Owns gear
- Checks forecasts frequently
- Will travel for better conditions

Goals:

- Maximize sessions
- Reduce wasted trips
- Find better spots
- Improve riding

---

## Secondary User

The Explorer

Characteristics:

- Travels for kitesurfing
- Loves discovering locations
- Adventure oriented
- Experiences over convenience

Goals:

- Find new locations
- Plan trips
- Discover hidden opportunities

---

# Product Hierarchy

Every screen should prioritize information in this order:

1. Opportunity
2. Intelligence
3. Spot Knowledge
4. Community Signal
5. Social Interaction

This hierarchy should guide all product decisions.

---

# Opportunity Layer

The most important layer.

Examples:

- Best Session Today
- Best Session Tomorrow
- Worth The Drive
- Hidden Opportunity
- Nearby Opportunity

The homepage should primarily focus on opportunities.

---

# Intelligence Layer

Transforms raw data into understanding.

Avoid:

23kt SW

Prefer:

Excellent conditions for your 9m kite.

Avoid:

Forecast table.

Prefer:

Recommended session.

The product should make decisions easier.

---

# Spot Intelligence Layer

Every spot should eventually have:

- Spot DNA
- Best wind directions
- Skill level
- Crowd level
- Water type
- Reliability
- Historical performance
- Seasonal performance

Goal:

Create a knowledge graph around spots.

---

# Community Signal Layer

Community should function as signal.

Examples:

- 12 riders active
- Last report 20 minutes ago
- Wind stronger than forecast
- Parking full
- Launch crowded

Avoid:

- social feeds
- endless commenting
- engagement mechanics

Community exists to increase confidence.

Not to create attention.

---

# Product Moat

The moat is not forecasts.

The moat is not UI.

The moat is not spot count.

The moat is:

- User profile
- Spot intelligence
- Session history
- Community signal
- Personalized recommendations

Over time Aeryo should know:

- preferred conditions
- preferred locations
- preferred travel distance
- preferred riding style

This creates defensibility.

---

# Design Principles

The product should feel:

- Premium
- Modern
- Confident
- Technical
- Adventurous
- Cinematic

Avoid:

- gamification
- visual noise
- tropical clichés
- social media aesthetics

---

# Visual Identity

Preserve:

- current color palette
- current typography
- current spacing system
- current component system

Future screens should feel like they belong to the same product.

Evolution.

Not redesign.

---

# Photography

Photography is strategic.

Images should communicate:

- atmosphere
- exploration
- anticipation
- weather
- scale

The feeling should be:

"Something interesting is happening nearby."

---

# Motion

Motion should feel:

- subtle
- intentional
- premium

Avoid:

- flashy animations
- attention seeking transitions
